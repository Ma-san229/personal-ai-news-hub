## 0. 守ること

- トークン、Webhook URL、パスワードをチャット、Issue、PR、ファイルに書かない。画面に出た値は、その場でMa-sanがGitHubの設定画面に貼る以外に使わない。
- Discordサーバーは本人専用の非公開にする。記事カードと反応が見えるため。
- 外部への送信（投稿）は、Ma-sanが確認してから有効化する。初回は「テスト」と明示した1通だけ送る。
- 分からないこと、権限が足りないことは、推測で進めず、止まって聞く。

## 1. 目的

GitHub Actionsが生成する日次ニュースを、Discordに届け、Ma-sanの絵文字の反応をGitHub側が読み取れる状態にする。GitHub側（Actions、データ、設定ファイル）は別のスレッドが作る。ここでは外部サービス側の準備だけを行う。

## 3. Botの権限（最小）

必要: チャンネルを見る、メッセージ履歴を読む。メッセージ内容の取得が必要かは、実装時にDiscordの公式資料で確認する（未確認）。
不要: 管理者権限、メッセージ削除、メンバー管理、ロール管理。

## 4. GitHubに登録するもの

リポジトリ: `Ma-san229/personal-ai-news-hub`
場所: Settings → Secrets and variables → Actions

| 種類 | 名前 | 内容 |
|---|---|---|
| Secret | `DISCORD_WEBHOOK_URL` | 手順2のWebhook URL |
| Secret | `DISCORD_BOT_TOKEN` | 手順3のBotトークン |
| Variable | `DISCORD_CHANNEL_ID` | 手順5のチャンネルID |

名前はGitHub側のActionsが参照するため、変えない。変える必要があれば、先にGitHub側のスレッドへ知らせる。

## 5. 絵文字と意味（GitHub側と共通）

| 絵文字 | 意味 | 点数への効き方（案） |
|---|---|---|
| 👍 | 刺さる | 加点 |
| 👀 | 追う | 小さな加点＋追跡候補 |
| ✅ | 既知 | 減点なし、再掲を減らす |
| 👎 | 弱い | 減点 |
| ❌ | 方向違い | 大きく減点 |

Discordに絵文字の対応表を、チャンネルの固定メッセージとして置く。

## 6. 完了の確認

次の4つを、値は書かずに報告する。

1. サーバーが非公開であること
2. Secrets/Variablesが3件登録済みであること（名前だけ）
3. テスト1通がチャンネルに届いたこと
4. Botが `news-daily` の履歴と反応を読める権限を持つこと
